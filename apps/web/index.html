      How SCADS works

      The problem with checking a code

      Serialisation puts a unique code on a pack, and a database can confirm the code was issued. It cannot confirm the code is on the pack it was issued for. Copy one real code onto a thousand counterfeit packs and every one of them passes.

      What SCADS adds

      Three independent kinds of evidence, fused so that contradictions survive instead of averaging away:

      Identity
      The code and the printed text are read separately and both checked against the registry. On a genuine pack they agree with each other.
      Physical pack
      The pack is located in the photo, rectified onto the enrolled reference artwork, and compared region by region — wording, position, structure and print detail.
      Scan history
      Where else has this exact serial been seen, and when? A unit serial identifies one physical pack, so the same serial in two distant places at once is a contradiction no database lookup can surface.

      Why not just average the three?

      Because averaging is how a copied code gets through. A flawless pack with a valid but cloned serial scores near-perfect on two dimensions out of three, and a weighted mean would call that low risk. SCADS combines them multiplicatively and applies hard caps, so a single decisive contradiction sets the result regardless of how good the rest looks.

      A bad photo is not evidence

      Blur, glare and darkness are measured before anything is compared. A photo too poor to judge returns Not enough evidence with advice on retaking it — never an accusation against the pack. Getting this wrong would mean telling people their genuine medicine is fake because their kitchen is dim.

      Built on AWS

      Amplify Hosting → API Gateway → Lambda → S3 (private, presigned direct upload) · Textract (OCR) · DynamoDB (registry + scan events) → deterministic decision engine → result. Bedrock is optional and can only restyle wording; it never decides anything.

      Limits worth stating plainly

      • A photograph cannot measure what is inside a pack. No active ingredient, no dose, no contamination.
      • Genuine packaging refilled with the wrong contents will pass every check here.
      • A copied serial may go undetected until it is scanned somewhere else.
      • The demo thresholds were set on synthetic fixtures, not on adjudicated counterfeit samples. They are not validated detection rates.
