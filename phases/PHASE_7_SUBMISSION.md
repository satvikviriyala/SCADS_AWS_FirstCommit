# Phase 7 — Submission

## Goal
Package only what judges can evaluate.

## Before submit
1. Verify rules/deadline.
2. Verify public repository.
3. Verify public URL in incognito.
4. Run full test/smoke suite.
5. Run secret scan.
6. Audit attribution/licenses.
7. Freeze stable commit.
8. Capture architecture diagram.
9. Record <=3-minute demo.
10. Submit early.
11. Only make low-risk improvements afterward.

## README final sections
- problem;
- why code existence fails;
- architecture;
- screenshots;
- demo;
- run locally;
- deploy;
- test scenarios;
- AWS services;
- limitations;
- roadmap;
- credits/AI tools.

## Video acceptance
A judge can identify:
- target user;
- failure of QR-only;
- physical signal;
- history signal;
- actual deployed AWS;
- working UI;
- limitation.

## Do not
- exceed 3 minutes;
- show imaginary features;
- use a fake accuracy metric;
- hide system errors with edited cuts that make the live product unreproducible.
